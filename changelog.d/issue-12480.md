A `cabal.project` file can now contain extension fields, i.e. fields whose name
starts with `x-`, at the top level, inside conditionals and inside every
stanza. Other tools can use these fields to keep their own data in the project
file. `cabal` ignores extension fields and no longer warns about them.

`Distribution.Fields` in `Cabal-syntax` now exports `extensionFieldPrefix` and
`isExtensionFieldName`. The parsers of package description files and project
files use them.
